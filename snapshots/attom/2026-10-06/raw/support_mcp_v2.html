MCP V2

ATTOM has launched MCP V2, the latest version of the ATTOM MCP Server, as part of the ATTOM Intelligence Platform.

MCP V2 provides an enhanced way to connect AI applications and workflows with ATTOM property data using the Model Context Protocol (MCP). It is designed to make it easier for customers to incorporate ATTOM data and intelligence into AI-powered applications, agents, and workflows.
