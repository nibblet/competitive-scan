Public API

FlipperForce Field is now available!

How it Works

The Public API gives you programmatic access to your FlipperForce data, enabling you to connect FlipperForce with other platforms, build custom integrations, and automate workflows between your investment tools and external systems.

What it does

The FlipperForce Public API exposes your workspace data through a RESTful API with standard authentication. Developers and technical users can read project data, pull financial records, and trigger actions in FlipperForce from external applications.

How to use it

Navigate to the Integrations section to generate your API key. Review the API documentation to understand available endpoints and data models. Use your preferred programming language or API tool (Postman, Zapier, etc.) to build integrations that connect FlipperForce to your CRM, accounting software, marketing tools, or custom dashboards.

Why it matters

As your real estate operation grows, your tools need to talk to each other. The FlipperForce Public API gives technical users and developers the flexibility to build exactly the integrations their business needs — whether that's syncing data with QuickBooks, pushing project updates to a custom investor portal, or automating reporting workflows.
