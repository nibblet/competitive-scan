# DealMachine API

> Documentation for the DealMachine REST API, CLI, MCP server, and real estate data integrations. Use name enrichment for a specific person. Use People Search for filter-defined audiences.

## Best way to inspect these docs

Download all docs as markdown files and grep them locally:

```bash
curl -L https://api.docs.dealmachine.com/docs.zip -o docs.zip
unzip docs.zip -d docs
grep -R "search term" docs/
```

Use this when you need to search across the whole documentation set. The zip contains every page as a .md file.
