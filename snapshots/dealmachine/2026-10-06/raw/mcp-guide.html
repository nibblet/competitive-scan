Connecting the MCP Server

The MCP server lets AI assistants pull DealMachine data for you: search, enrich, and run comps right from a chat.

4 min read

DealMachine as an AI tool source

The MCP server is deployed at https://mcp.dealmachine.com. Connect it to an MCP-capable client like Claude Desktop or Cursor and the assistant gains DealMachine MCP Tools: enrichment, property and people search, comps, and account lookups.

Add it to Claude Desktop

{
  "mcpServers": {
    "dealmachine": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://mcp.dealmachine.com",
        "--header",
        "Authorization: Bearer dm_sk_live_xxx"
      ]
    }
  }
}

Use an API key from Settings → Developer in place of the placeholder.

What the assistant can do

  • Enrich by address, lat/long, APN, email, phone, or name
  • Search and count properties and people
  • Run comparable-sales analysis
  • Look up locations and check your credit usage

Same credits, same free actions

MCP Tools spend credits exactly like the rest of DealMachine: one per unique record, deduplicated per cycle. Counts, filter and field discovery, location lookups, and usage checks are free.
